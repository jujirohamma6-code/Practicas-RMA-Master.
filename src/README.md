# Contavex · Sistema Contable Integrado (MVP)

Sistema contable desarrollado en Electron para escritorio, diseñado como reconstrucción modular inspirada en Mónica 9.

## 🚀 Módulos Incluidos (10 Módulos)
1. **Facturación:** Gestión de ventas y comprobantes.
2. **Cuentas por Pagar (CxP):** Administración de pasivos y obligaciones.
3. **Cuentas por Cobrar (CxC):** Registro de crédito y clientes.
4. **Estimados:** Proyección de presupuestos y cotizaciones.
5. **Contabilidad:** Libro diario, mayor y catálogo de cuentas.
6. **Cuentas Corrientes:** Conciliación bancaria y emisión de cheques.
7. **Inventario:** Control de existencias y productos.
8. **Clientes y Proveedores:** Directorio comercial unificado.
9. **Parámetros:** Configuración del sistema y tasa de cambio.
10. **Manual:** Guía de usuario y documentación.
